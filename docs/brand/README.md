# Seamline brand

A seam line is where two regions meet, which is what segmentation draws. The mark draws that line as an S with three editing handles, splitting the plate into two classes.

## Files

| File | Use |
|---|---|
| `seamline-mark.svg`, `seamline-mark-512.png` | The mark, at 40 px and up |
| `seamline-mark-small.svg` | The mark below 40 px: no handles, thicker line |
| `seamline-logo-on-dark.svg`, `.png` | Mark and name, for dark backgrounds |
| `seamline-logo-on-light.svg`, `.png` | Mark and name, for light backgrounds |
| `../../app/resources/icon.png` | Window icon, with a small margin |

The name in the logo files is outlined, so they need no font installed.

## Colours

| Colour | Hex | Use |
|---|---|---|
| Blue | `#4f8cff` | Left of the seam, and the app's accent |
| Deep blue | `#1f49ad` | Right of the seam |
| Ink | `#14161a` | The seam line, and the app's background |

## Type

[Inter](https://github.com/rsms/inter) (SIL Open Font License 1.1): semibold for the name, and the app's whole interface.
