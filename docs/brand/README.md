# Seamline brand

A seam line is where two regions meet, which is what segmentation draws. In the mark the seam is an S where two sides meet: a dataset on the light side, a network training on it on the dark side. The S is not drawn; it is only the edge between the two. Three editing handles sit on it, and the dark side casts a soft shadow, so the S reads first and the detail stays quiet.

## Files

| File | Use |
|---|---|
| `seamline-mark.svg`, `seamline-mark-512.png` | The mark, at 64 px and up |
| `seamline-mark-small.svg` | The mark below 64 px: the two sides and a lighter shadow, no detail or handles, a firmer rim |
| `seamline-logo-on-dark.svg`, `.png` | Mark and name, for dark backgrounds |
| `seamline-logo-on-light.svg`, `.png` | Mark and name, for light backgrounds |
| `../../app/resources/icon.png` | Window icon, with a small margin |

The name in the logo files is outlined, so they need no font installed. A faint grey rim keeps the mark's outline on pages the colour of either side.

## Colours

| Colour | Hex | Use |
|---|---|---|
| Paper | `#f3f5f9` | The data side of the seam |
| Ink | `#1b1f28` | The training side of the seam |
| Handle ink | `#14161a` | The rings on the handles, and the app's background |
| Blue | `#4f8cff` | The app's accent |

The detail on both sides is the side's own tone at about a third of its strength, in greys only.
